# Bile Acids and Mixed Micelle 3D

This repository combines two independent interactive molecular viewers:

- **Bile acids - interactive 3D**, powered by JSmol
- **Mixed micelle3D**, powered by Three.js

The bile-acid viewer is the default root page. Each viewer contains a visible
button that opens the other viewer.
